# Spike 结论：持球盲区补训（R-018）——终局失败

日期：2026-10-17 ｜ 裁决：**双门皆败，低于止损线 → Spike 终局，补训路线关闭，HSV 永久保留**
评估脚本：`诊断/2026-10-17-持球Spike/eval_spike.py`；原始数据：同目录 `eval_spike.json` / `eval_run2.log`

## 1. 训练概况

- `runs/held_spike_v1`（yolo 仓）：yolov8n fine-tune，imgsz 1280、batch 4、**12 epoch 早停**（patience=10，fitness 最优在 epoch 2 附近），实际耗时 0.55h。
- 训练数据：原 train/val（按 manifest 重抽）+ 91 帧两遍制人工严格集（持球段，来源 09-12_1 / 09-19_1）。
- val（原 val 集）：mAP50 ≈ 0.49、mAP50-95 ≈ 0.356，与基线相当——持球补样没能带动整体。

## 2. 裁决数字（主口径：conf 0.05，R=60px；完整敏感性见 eval_spike.json）

**硬门① 持球段召回 ≥50%**（出手前 0.9~0.2s，6 帧/球，40 球/场，锚=release_xy）：

| 场 | base@1024 | base@1280 | **spike@1280** | 判定 |
|---|---|---|---|---|
| 09-04_1（held-out） | 0% | 0% | **5.0%** | ✗ |
| 09-11_3（held-out） | 0% | 0% | **7.5%**（R80 也仅 10%） | ✗ |
| 10-10_1（held-out） | 0% | 0% | **2.5%** | ✗ |
| 09-19_1（**训练场**） | 2.5% | 2.5% | **40.0%**（R80 达 47.5%） | 参考项 |

**硬门② 飞行段召回降幅 ≤5pct**（出手后 0.2~1.0s，锚=任一 HSV 合格候选）：

| 场 | base@1280 | spike@1280 | Δ |
|---|---|---|---|
| 09-04_1 | 100% | 100% | 0 ✓ |
| 09-11_3 | 77.5% | 82.5% | +5 ✓ |
| 09-19_1 | 82.5% | 97.5% | +15 ✓ |
| 10-10_1 | 87.5% | **62.5%** | **−17.5 ✗** |

**判定：held-out 持球召回最高 7.5%，不仅远低于 50% 过门线，也低于 30% 止损线；且 10-10_1 飞行段回退 17.5pct（配比反噬应验）。双门皆败 → 终局。**

## 3. 归因

1. **过拟合训练场、零泛化**：spike 在自家训练场 09-19_1 把持球召回从 2.5% 拉到 40%（确实学会了「这两场的持球长什么样」），但换一场就归零（2.5~7.5%）。持球视觉特征（手部遮挡形态、袖口/肤色/光照、机位）高度场特定，2 场 91 帧不足以支撑跨场泛化。
2. **val 集无感**：mAP50-95 0.356 ≈ 基线，持球样本占比太小（91 帧对 ~4300 帧）且 val 里没有持球负/正样本可暴露问题。
3. **飞行段反噬实锤**：10-10_1 降 17.5pct、g0.15 下降更狠（47.5%），持球样本干扰了飞行特征的置信度分布。
4. **方法学已到头**：此前已证纯自动标注不可行（4 种特征全不可分）、HSV 预标注在真持球时不可靠；本次证明**少量人工标注 + fine-tune 也无法买来泛化**。要泛化需要多场、多机位、数百至上千帧人工持球标注——成本远超 HSV 链维护成本，且不保证成功（小目标+遮挡本质困难）。

## 4. 口径备注（与方案 §0 的差异，均已实测修正）

1. **基线场次修正**：方案引用的「基线 4/40、8/40」实为 Phase0 §5 在 09-19_1 / 10-10_1 的抽检（口径更宽）；本次按统一脚本实测 base 在 held-out 场持球召回为 0~2.5%——基线比方案预估更低，不改变判定方向。
2. **飞行段锚**：初版用「HSV 最大 blob」作锚，09-04_1 系统性锁错（重合率 2.5%），改「任一合格 HSV 候选」后 4 场 base 飞行召回 77.5~100%，符合生产链实测水平。两模型同锚，公平。
3. **R 敏感性**：R=40/60/80 差异很小（球检出框中心贴球心），主口径 R=60 不影响判定。
