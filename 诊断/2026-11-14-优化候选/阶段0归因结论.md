# L0 复现差异归因（阶段 0 结论）

日期：2026-11-14 · 范围：老六 + 新六共 12 场、3773 条剔除后事件 · 只读

## 结论

`replay_l0.py` 报的 **153/3773 不一致全部有单一机制解释，不存在版本常量漂移**。
原方案里我押的「B v20/v22 常量漂移最可能」**是错的**，实测常量一位都没漂。

| 主因 | 条数 | 占比 | 机制 |
|---|---|---|---|
| **1. B2 注入行漏了网分例外** | 77 | 50.3% | `net_motion.net_term()` 对 `review_reason=="b2"` 返回 0（注入行 conf 未含网分），`replay_l0.py` 无条件加了网分 → Δ = +0.30 / +0.26 |
| **2. 侧分跨度的三位小数边界** | 62 | 40.5% | `above_span/below_span` 存 3 位小数，真实 0.1995~0.1999 被存成 `0.200`，replay 判「满档 0.20」，实际走「短档 0.14」→ Δ = −0.06 |
| **3. 位置分的档位边界** | 14 | 9.2% | `cross_off` 存 3 位小数，真实 0.1004 被存成 `0.100`（−0.100 同理）→ 档位错一档 → Δ = −0.03 / −0.04 / −0.12 |
| 合计 | 153 | 100% | 三条互斥、无残差 |

旁证：
- 77 条 Δ∈{±0.30,±0.26} 的 `review_reason` **100% 是 b2**（`Counter` 结果唯一）。
- 全库 `net_post == 5.0` 只有 3 条、5.0±0.005 内非等值 0 条 → **网静止阈值没有翻转混入**。
- 「conf 一致但 status 不同」= 0 → 没有第三条隐藏路径。

## 修法（已验证 100% 复现）

不需要退化到 L1，也不需要重跑检测。关键洞察：

> 存储的 `confidence` 本身保留了方向。`geom = round(conf − net, 2)` 是精确的
> （两项都是 2 位小数），而 `geom = 0.3 + 侧分×2 + 位置分`，三个分量分别取自
> 离散集合 → **可以从 conf 反解出真实档位**。

做法：
1. **b2 例外**：`review_reason=="b2"` 的行网分按 0（与 `net_term` 对齐）。
2. **档位反解**：只对**真正有歧义**的维度（存储值距档位界 ≤0.0005）枚举，其余维度由存储值锁定。否则 `0.14+0.20` 与 `0.20+0.14` 同和会造伪解（首版就踩了这个坑：多解 1876 条）。
3. **微调入档**：反解出档位后把混淆值往档位内侧挪 0.0005（`0.200 → 0.1995` 表示真实 <0.2）。此后任何阈值比较都天然正确，只有阈值恰好落在 ±0.0005 内才会再歧义。

## 影响面

- 修法只改**离线复算工具**，不碰 `bbh/`、不碰任何 `events.json`、不改口径。
- 修正后 L0 的能力边界不变：仍只能验「打分形状 / 阈值 / 网分权重 / 基于事件时刻的规则」；`CROSS_KILL_OFF`、冷却、几何门槛、标定仍必须走 L1。
- 存储精度这次不是「损失」，而是「可反解」——只要不删 `confidence` 字段，L0 在这些维度上是精确的。
