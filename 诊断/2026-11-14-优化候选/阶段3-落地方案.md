### 1. 生产代码（唯一实质改动）

**`bbh/goal_decider.py:169-178`** `_side_score()`：

```python
def _side_score(n: int, span: float) -> float:
    if n >= 2 and span >= CONT_SPAN_SEC:
        return 0.20
    if n >= 2:
        return 0.14        # ← 改成 0.17（建议同时抽常量 SIDE_SHORT = 0.17）
    if n == 1:
        return 0.05
    return 0.0
```

理由：真球 68% 的 `above_span < 0.2`（球速快、筐口上方停留短），假绿只有 23%。
现行「跨度不够就砍到 0.14」系统性惩罚真球。补 0.03 让这批跨过 0.60 门槛。
