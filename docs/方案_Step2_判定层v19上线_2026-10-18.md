#### 2.3.0.1 D14-A 落地设计：`--union-blocks`（评测仓 workaround，已裁定 ✅）

**问题本质**：`P._blocks_from_doc(doc, video_path)` 返回 `{指纹: 块}`；首尾同机位的两段共享同一指纹，字典只保留后写入的块 → 时间窗只覆盖一个段 → 另一段 `_block_covers` 失败 → 重扫中止。

**修法**（只在 `yolo/scripts/replay_layer.py`，~20 行，不碰生产仓、不碰快照代码）：

- 新增 CLI 开关 `--union-blocks`（默认关；控制臂与 v19 重放显式打开）
- 打开时 monkeypatch `P._blocks_from_doc` 为"不去重版"：用 `P._parse_block(seg)` 逐段建块，按 `P._ktuple(seg_key)` **分组求并集**——同指纹各段的位置/位移合并排序，`t0` 取组内最小、时间窗并集；**键保持原指纹**（段 key 原样命中，不用 `AUTO_KEY`）
- 因此**不需要 SegShim、不换筐几何**——与 `--hoop` 模式（自动筐实验）本质不同，几何仍用 `calib_recover` 的生产人工标定，与 run_ab 全片跑完全同源
- 单段场分组后就是原样，行为不变（5/7 场等价空操作）

**正确性证明 = 控制臂本身**：`v18_ctrl`（带 workaround）7 场逐行 (t, status, confidence) 100% 复现 `v18_c03_s1`（含 09-04_1 / 09-11_3 两场）→ 并集块与全片跑等价、无副作用。任何一场失败 → 停，先归因（块时间窗语义 / 点排序 / 位移合并），不带病跑 v19。

> 实现顺序：先写 `--union-blocks` + 用预检验证 09-04_1 / 09-11_3 块覆盖转绿 → 再跑控制臂 → 过关才 v19。

#### 2.3.3 反作用监测三场改为离线复算（不重放）

三场的生产 `events.json` 是 `logic_ver=18`，且每行都存了 `confidence` + `net_post` / `net_ctrl` / `net_local` + 硬门标志 → **status 可 100% 复现**（Step 1 已在 10 场 3164 行上验证：3164/3164）。

- `10-10_1` 点流是 **2 个段**，正落在 D2① 射程内；若块未命中，`--allow-rescan` 会触发整片 HSV 补扫（1 小时）
- 这三场只用来看"非自动档条数有没有暴涨"，不需要新的事件集，复算足够
- 复用 Step 1 的复算器口径：`conf_new = conf_stored + (net_score_new − net_score_old)`，硬门行档位不动

**交叉验证**：`09-24_1` 已有 `eval_out/v18_reverse` 真重放产物 → 用同一份点流复算一次，必须与重放结果完全一致；一致才把复算结果用于 `10-10_1` / `10-16_1`。
