> ## 否决结论（先看这段）
>
> Step 1 用只读探针 `诊断/2026-11-07-筐识别/autoseg_probe.py` 在 5 场跑完，

>    但用户 46:15 补过段——那次机位只挪 31px，ORB 跟得住。上游 12 场 19 段

> 2. **判据二（筐残差）也不触发。** 用「段1标定 + ORB」预测全片筐位，与实测
>    比：10-30_1 0.04~0.08W、10-23_1 0.03~0.07W、10-31_1 0.01~0.02W、

>    「参考帧 PNG vs 视频帧」的逐场恒定偏置，随时间只缓变 3~5px，不是突变。
> 3. 推论：**用户手工补的 7 个段在几何上全是多余的**；照本方案实现，
>    12 场 0 次触发 = 死代码，且多一个「造出假段」的风险。
>
> 改为做成本更低的两件事（v22，已实施）：**①** 校正采样孔洞告警分两档
> （30s 轻提示 / 180s 重警告，带具体时刻），真被挪镜头时主动提醒人；
> **②** 流程上明确「多数场次只需标一次」，多段标定降级为可选。
>
> 重启条件：出现**大挪位真案**（三脚架整场搬位置、ORB 失配 ≥30s 且残差
> 持续 >0.30W），且用户明确要求自动化。

## 1 目标

用户拍一场比赛，**只需要在片头点一次筐**。视频中途机位被碰/挪走后，
系统自动发现跳变、自动取新参考帧、自动用筐桥接合成那一段的标定，
不再需要人工「跳到移动后时刻 → 再点一次筐」。

已验证的前提（`诊断/2026-11-07-筐识别/结论_v21验收.md` 附录）：

- 用「段 1 标定 + 筐心位移」预测用户手点的后续各段筐位，6 个需补段误差
  **中位 0.05 / 最大 0.12 筐宽**（不桥接是 1.18 / 1.87），验收线 0.15。
- 判定层同口径对照（`sim_one_calib.py`）：只标一次+筐桥接 vs 人工多段，
  查准 71.72 / 72.97（−1.25pct），查全 79.09 / 77.00（**+2.09pct**），
  命中 416 vs 405。基本打平、查全略好。
- 反向对照：只标一次**不用**筐桥接 → 命中 405→213、查全 77%→40%，崩。

所以缺的只剩「自动切段」这一块工程。

---

## 2 关键判据：什么情况才算需要补段

**只有 ORB 跟踪真的断了才补段。** 理由：

- 机位小幅被碰（几十 px）时 ORB 仍能配准，位移表照常跟踪，不需要新段；
- 只有挪动幅度大到与旧参考帧**失去可匹配的重叠区域**时，才会连续失配
  （`motion.MATCH_MIN=20` / `MAD_MAX_PX=6.0` 拒收）→ 校正冻结 → 检测框盯空气
  （09-04_1 实测：t≈1525 挪位后片尾 79% 检测框盯空气，high 占比 48%→7%，全程静默）。

所以判据取「**连续失配时长**」，不用位移步长（步长对缓慢摇镜会误报）。

| 参数 | 值 | 含义 |
|---|---|---|
| `SCAN_EVERY` | 150 帧（5s） | 粗扫采样间隔，与 `motion.SAMPLE_EVERY` 一致 |
| `FAIL_RUN` | 6（30s） | 连续失配样本数达到即判跳变 |
| `REFINE_SPAN` | ±10s、1s 步长 | 边界精化窗口 |
| `REF_WINDOW` | 跳变后 0~15s | 候选参考帧窗口 |
| `HOOP_CONF_MIN` | 0.25 | 参考帧上筐检出下限 |
| `SIZE_RATIO_OK` | 0.70 ~ 1.40 | 桥接时允许的尺寸比（超界=疑似变焦，不自动补） |
| `SUSPECT_W` | 0.30 筐宽 | 事后校验：≥3 个样本超此值即标记可疑 |

## 3 算法（`bbh/autoseg.py`，新增）

```
plan(video_path, segs, work_dir) -> (segs2, notes)
```

1. **粗扫**：以**最后一段**的参考帧为基准，每 5s 取一帧跑 ORB 匹配，
   记录 (t, ok, dx, dy)。连续 `FAIL_RUN` 次失配 → 在最后一次成功之后存在跳变。
2. **精化边界**：在跳变点 ±10s 内按 1s 逐点测，取「最后一个仍能匹配的帧」
   与「第一个持续失配的帧」，新段 `t0` = 后者（回退 1 帧余量）。
3. **选干净参考帧**：`[t0, t0+15s]` 内每 1s 取帧打分：
   筐检出 conf ≥ 0.25 **且** 筐框尺寸最接近上一段 **且** Laplacian 方差最大。
   落盘 `calibration_ref_segN.png`。
4. **合成标定**（筐桥接）：
   ```
   hoop_rect_new = hoop_rect_1 + (hoop_ref_new.center − hoop_ref_1.center)
   尺寸比 r = w_new / w_1 ∈ SIZE_RATIO_OK 时按 r 缩放 w,h，否则不缩放 + warning
   hsv_low/high、frame_size 抄段 1
   calib_t = t0, ref_image = 新 png, ref_hash = md5
   新增字段 auto=True, auto_from=1
   ```
5. **落盘**：`calibration_seg{max+1}.json`。已存在 t0 相差 <1s 的段（用户手补过）
   → 不创建。`auto=True` 的段每次重算，t0 差 <3s 则直接复用不重扫。
6. **事后校验**：新段内均匀取 5 个时刻，用「新 ref 的 ORB + 桥接」预测筐位
   与检测比；≥3 个样本误差 >0.30 筐宽 → 标记 `auto_suspect`，段保留但加
   warning「自动补段可能不准，建议手动补一段」。**不静默、不自动删。**

成本：2 小时视频粗扫 1440 帧 ORB ≈ 10~15s，精化 20 帧，参考帧候选 15 帧
× (ORB + 1 次 YOLO) ≈ 1s。

## 5 顺手要收口的一项（建议同批做）

`BBH_HOOP` 目前默认开 = 逐帧校正生效，而它已被证净亏（五场查全 −0.92pct，
10-17_1 −9.87pct）。建议改为**默认只采样不搬点**：
`hoop` / `hoop_ref` 照常采样落盘（桥接要用），但 `_hoop_apply` 默认不改坐标。
这样既保住桥接能力、又不再损伤判定。开关拆成两个：
`BBH_HOOP`（采样，默认开）、`BBH_HOOP_SHIFT`（逐帧搬点，默认关）。

## 7 风险与回退

| 风险 | 处置 |
|---|---|
| **误检**（长时间遮挡/大雾/模糊被当成跳变） | 粗扫要求连续 30s 失配；参考帧必须筐 conf≥0.25 且落盘后再做一次 ORB 自检（与 t0+30s 帧能匹配）。误检的后果是"多一段"而非"删数据"，可手动删 |
| **参考帧选到模糊帧** → 该段全程失配，比现状更差 | 参考帧落盘后 ORB 自检 + Laplacian 方差门 |
| **变焦**（尺寸比超界） | 不自动补，只加 warning 让人工补 |
| **HSV 检测器**（颜色几何都变，抄段 1 的 HSV 会错） | 只在 `detector_switch.NAME == "yolo"` 时启用；HSV 下跳过 + warning |
| **段边界事件**（跨段重复/漏） | 走既有 `_merge_segment_events` 冷却去重；验收专门看边界 ±30s |
| **用户不知情** | 段列表显示「自动」+ 可删；warning 写明时刻与来源段 |

回退：`BBH_AUTOSEG=0` 一键恢复；删掉 `calibration_segN.json`（`auto:true`）即回到
人工多段。**不修改、不删除任何既有文件。**
