# 单页工作台 UI 重设计

日期：2026-08-16
状态：设计已与用户逐节确认

> **📌 历史文档（过程存档）**：单页工作台已按本文实施。此后 UI 又迭代了
> 生成集锦弹窗（含按人统计）、打标面板化、逐项生成进度反馈、预览默认
> 2 倍速等。现行操作说明见 `README.md`「使用」节。

## 背景与目标

现有 Gradio 界面分三个 Tab（① 标定 / ② 分析 / ③ 集锦），实际使用痛点：

- 同一视频路径要在 ②③ 各填一次（标定参考视频另算）
- 检测几十分钟，切到别的 Tab 就看不到进度
- 集锦页单列超长：点一行表格 → 滚到底看预览 → 滚回来点下一行；生成按钮在最底部

用户使用模式为**一条龙**：每周一次"新视频进来 → 检测 → 复核打标 → 生成"一口气做完。
目标：主线收敛为**一个页面**，复核环节（每周耗时最多）零滚动。

## 已确认的决策

| 决策点 | 结论 |
|---|---|
| 页面结构 | 主页「剪辑台」+ 独立「⚙ 标定设置」Tab（用户选 D） |
| 布局 | 双栏工作台，**预览为主**：左窄栏流水线，右主栏预览（用户定调） |
| 表格 | 留左栏，精简 4 列：☑ 选中 / 时间 / ●置信度 / 标签（A1） |
| 完整数据展示 | 右栏当前行面板加 ℹ 图标，hover 弹完整数据卡（A，Dataframe 不支持行内 tooltip） |

## 页面结构

### 主页「剪辑台」

```
┌─────────────左窄栏（约 30%）─────────────┬────────右主栏（约 70%）────────┐
│ ① 视频与检测                              │ 预览播放器（主角，约 2/3 宽）    │
│    路径输入 + ▶ 开始检测（续跑同入口）        │   蓝|红|绿分色进度条，静音自动播 │
│ ② 进球列表（4 列，内部滚动）                 ├──────────────────────────────┤
│    ☑ 00:42 ●0.9 小王                      │ 当前行面板                      │
│    点行 → 右侧立即预览                      │   第 N 条 · 时间 · 状态 · 标签   │
│ ③ 全局 前[15]s 后[5]s [应用]               │   前 [15] 后 [5] ↻按此重切预览  │
│    折叠「更多调整」：时刻校准 + 重新载入      │   判定依据一行 + 置信度算式      │
│ 🎬 生成集锦 MP4（主按钮，常驻可见）           │   ℹ hover 完整数据卡            │
│                                           ├──────────────────────────────┤
│                                           │ 标签按钮行 + [+ 新名字…]        │
└───────────────────────────────────────────┴──────────────────────────────┘
```

### ⚙ 标定设置 Tab

现有标定页**整体搬迁**，交互不变：上传/路径抽帧、跳时间抽帧、gr.Image 点选
（筐口左端、右端、球 1-3 次）、HSV 微调滑杆、预览验证。主页检测按钮旁放首次
引导语（"没标定？先去 ⚙ 标定设置"）。

## 状态流转

1. **空闲 → 检测中**：右栏与左栏下半区置灰或隐藏（实现取更顺手者）；进度条
   顶到表格区（已分析时长/总时长），不切 Tab 也常驻可见
2. **检测完成 → 自动载入表格**，直接进复核（取消现有"载入检测结果"按钮环节）
3. **生成 → 成品替换预览位播放**，旁边「回到逐条预览」按钮还原

## 数据模型与编辑路径

表格只显示 4 列，但**完整行数据（含每条的前秒/后秒/状态/置信度）存页面
gr.State**，表格是投影。三条编辑路径写回同一份 State：

1. 表格直改：勾选、标签（input 事件同步 State）
2. 当前面板：单条前秒/后秒数字框 + 「↻ 按此重切预览」（改完即看效果）
3. 全局前后秒 + 应用到全部（批量兜底）

ℹ 完整数据卡：右栏面板用 gr.HTML 渲染，CSS hover 卡片显示该行全部字段
（前后秒、状态、置信度、判定依据全文、疑似弹出等）。

已知限制（用户接受）：gradio Dataframe 无当前行高亮，靠右栏面板
"当前：第 N 条"标识。

## 保留不动的行为

均为已踩坑验证过的实现，不重造：

- 点行预览链路：帧精确重编码、静音自动播放（muted）、`?v=mtime` 缓存击穿、
  分色条按行实际裁剪长度推导
- 标签系统与持久化：tags.json / tag_assignments.json 格式不变，老数据直接沿用
- 检测后台续跑、2s 轮询、0 命中诊断、检测前自动转码
- 生成逻辑与输出：highlight.mp4 / highlight-<标签>.mp4、片段不合并
- 判定依据输出与置信度细化（本分支既有工作）

## 错误处理

- 无标定点检测 → gr.Error 指引"先去 ⚙ 标定设置"
- 检测完成 0 命中 → 表格区显示诊断入口（沿用现有诊断）
- 路径错误/视频打不开 → 沿用现有报错文案
- 已有 events.json → 输入路径后自动探测，提示"已有结果已载入；重新检测将覆盖"

## 测试与验收

- 单元测试：投影/写回一致性（表格改勾选→State 同步；面板改前后秒→对应行
  更新）、ℹ 卡含全部字段、检测完成自动载入、无标定报错指引
- 现有 114 测试：底层（检测/判定/剪辑/持久化）全保留，改集锦页表格相关十几个
- 手工验收：30 分钟真实视频从填路径到出集锦一条龙，复核零滚动
