# 抖音 2s / 5s 完播率：一页执行清单

日期：2026-10-31　对象：篮球进球集锦（现有 YOLO 管线产物）
前提：**现有生成规则一行不改**，只在成片之后做二次剪辑

---

## 结论

完播率差的根因不是剪辑审美，是**进球被排在第 5 秒**。抖音的 2 秒、5 秒判定点全落在"球还没出手"的空白画面上。要动的第一件事是进球在时间轴上的位置。

---

## 现在的问题（逐帧实测）

| 项 | 实测 | 后果 |
|---|---|---|
| 单球成片 | 8.1s，**进球在第 5.0s** | 2s/5s 判定点 = 空白画面 |
| 0.0s 首帧 | 人站着，球不在画面内 | 没有钩子 |
| 全场合集 | 19.5 分钟 | 完播率趋零 |
| 按人合集 | 57~110s | 超甜点区，断崖 |
| 分辨率/码率 | 660×1280 / 2.3 Mbps | 低于标准，上传再被压 |
| 画幅 | 上下各约 95px 纯黑边 | 平台明确列为完播负因子 |
| 文字层 | 无 | 静音刷 = 零信息 |
| 单球钩子 | 无（`vrender.py` 注明"单球恒 hook=None"） | 纯线性铺垫 |

## 目标形态：25 秒 / 7~8 球

```
0.0-0.6  穿网前置（最炸球那 0.4s，0.5× 慢放）
0.6-1.0  白闪 + 标题条（≤12 字）
1.0-4.0  球 1：出手 → 进球 → 落网
4.0-7.0  球 2
……
22.0-25  最炸一球完整版 + 0.5s 定格
```

硬规则：
- 每球 2.8~3.0s，**进球落在每个 3s 小段的第 1.4~1.8s**
- 2s 判定点必须是"球已进"；5s 判定点必须是"第 2 球已进"
- 慢放只给 top 30%，其余快切，制造落差

## 验收

指标只看四个：2s 完播 / 5s 完播 / 平均播放时长 / 完播率。

同一球池出 3 条 25s 版，与现有作品对比：**5s 完播提升 ≥10 个百分点**即算结构有效。一次只改一个变量。

---

## 三个风险

1. **进球定位误差 >0.3s** → 钩子剪到空镜头。缓解：先标定再批量。
2. **660 放大到 1080 是假高清** → 只是符合上传规格，信息量不变。真想清晰只能回原片。
3. **二次编码再损一层** → crf 18 + preset slow，与原件对比 PSNR。
